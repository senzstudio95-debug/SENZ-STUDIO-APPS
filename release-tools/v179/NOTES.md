- Auto Arrange menggunakan inci untuk ukuran petak, margin dan gap. Gap awal 0.15748 in (4 mm), boleh diubah.
- Seret tajuk window untuk pindah. Petak canvas boleh diseret pada tepi dan diubah saiz pada penjuru tanpa menekan Edit dahulu.
- Pilihan All objects and text, All text, atau Selected objects. Saiz asal, kumpulan dan objek terkunci dikekalkan.
- Pilihan canvas mengemas kini warna secara langsung. Only this menyusun warna tersebut sahaja; checkbox membolehkan beberapa warna dipilih.
- Auto update menggunakan sehingga empat sambungan bagi installer besar, retry bahagian gagal, fallback satu sambungan jika range tidak disokong, dan semakan SHA-256 sebelum pemasangan.
