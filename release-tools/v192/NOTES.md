SENZREADER is now built directly into SENZ Studio. No separate bridge installer is needed.

- Receive Chrome orders in a movable, resizable review window.
- Font search, font uploads and removal, code mapping, Title Case / UPPERCASE / lowercase.
- Stroke in inches, word gap, letter spacing, large color swatches and optional logos.
- Add prepared names to the canvas while keeping its zoom and the reader window open.
- Chrome scanner highlights only orders without a Customer message label.

Open SENZREADER in Studio, then Install Chrome Extension. Chrome requires Developer mode > Load unpacked once; the extension folder is supplied by Studio. Existing extension users can use Connection to pair.

Built from the checksum-verified v2.9.191 release. Existing unrelated app files are preserved.
