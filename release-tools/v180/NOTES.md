Vector Box untuk teks, shape, ikon dan imej/vector.

- Objek kekal boleh edit, ubah saiz dan warna selepas Vector Box diaktifkan.
- Warna Vector Box disimpan berasingan dan kekal apabila warna objek ditukar.
- Kawalan Vector Box biasa dan Focus Mode menyokong semua jenis objek.
- Kotak mengikuti saiz objek dan disimpan bersama projek.
- Mengekalkan Auto Arrange inci, gap boleh laras dan muat turun pantas versi sebelumnya.
