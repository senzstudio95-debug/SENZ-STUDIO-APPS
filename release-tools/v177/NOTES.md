Baiki resize tulisan yang kadangkala gagal dengan mesej “This size is too small for the current thickness or letter spacing.” Saiz kini dikira daripada bentuk tulisan lengkap dan diskalakan sekata, termasuk ketebalan serta jarak huruf. Teks kekal boleh diedit. Pembetulan digunakan oleh Size Tool dan pilihan saiz Focus Mode.

Fungsi lain dan demo 7 hari dikekalkan. Ujian regresi resize, interaksi dan integriti installer dijalankan sebelum penerbitan. Pemasangan Windows sebenar belum diuji.
