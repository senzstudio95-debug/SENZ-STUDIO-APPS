Memeriksa tetapan sambungan…

Selepas anda memberi kebenaran di TikTok, token API diterima dan disimpan secara automatik di server. Anda tidak perlu menyalin token TikTok ke aplikasi.

Kunci akses SENZ & tetapan sambungan

Kunci ini melindungi order kedai anda. Ia bukan App Secret atau access token TikTok. Ambil CONNECTOR_TOKEN daripada Variables di tetapan server.

Masukkan kunci akses SENZ untuk membaca order. Token hanya disimpan dalam memori tetingkap ini.

Redirect URL: https://senz-tiktok-production.up.railway.app/tiktok/callback

Pilihan reka bentuk

Pilih tetapan untuk order baharu, atau gunakan kepada order yang ditanda. Lebar diukur dalam inci.

Order untuk semakan

Setiap order mempunyai pilihan font, saiz dan warna sendiri. Isi nama custom dengan tepat; mesej pembeli ialah rujukan sahaja.
